# Hire and Hired Stars

HHS connects candidates and companies with career opportunities.

## Frontend

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

Create a production build with `npm run build`. Run ESLint with `npm run lint`.

Company profile and recruiter verification are available at `/companies/profile`.
Companies apply for verification first; each recruiter then submits a separate
application after the company has been verified.
